# Sistema de Gestión y Comercialización para Tienda de Indumentaria

## Descripción

Proyecto desarrollado en el marco del Trabajo Final Integrador.

El objetivo es desarrollar un sistema web para gestionar los principales procesos de una tienda de indumentaria, incluyendo la administración de productos, stock, clientes y ventas, junto con un catálogo digital para la consulta de productos.

## Estado del proyecto

En desarrollo.

Actualmente el proyecto se encuentra en etapa de planificación y diseño.
